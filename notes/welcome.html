Welcome & How These Notes Work

This repository is a personal, plain-HTML notebook. There is no build step, no server, no framework and no database. Every note is a single, self-contained HTML file that you can open by double-clicking it in any modern browser.

The one rule

Each new topic gets its own new HTML file inside notes/. Notes that already exist get edited in place, not duplicated.

How notes are organised

  • index.html — the contents page. Lists every note and has a search box. Open this first.
  • notes/<topic>.html — one file per note. Fully self-contained: styles are inline, no external files needed.
  • templates/note-template.html — a starter skeleton for new notes.

Writing a new note

  1. Decide the topic — e.g. "Git rebase basics".
  2. A new file is created at notes/git-rebase-basics.html, copied from the template.
  3. The note is written in full, inline CSS included, so the file works standalone.
  4. A card linking to the new note is added to index.html on the contents page.

Modifying an existing note

If the topic already has a note, that file is edited in place — rewritten or extended — and the contents page entry is updated only if the title or summary changed.

Viewing your notes

Just open any .html file in a browser:

# Linux
xdg-open index.html

# macOS
open index.html

# Windows
start index.html

No internet connection is required — fonts are system fonts and everything is inline.
